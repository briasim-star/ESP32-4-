PEMF Controller - Install Firmware

  1. Plug the ESP32 board into a USB port on this computer.
  2. Use Chrome or Edge (Web Serial required - Safari/Firefox won't work).
  3. Click Install below, then pick the correct COM/serial port when prompted.
  4. Wait for it to finish - do not unplug during flashing.

This installs the latest automatically-built firmware from the project's GitHub repository. All data on the board will be erased and replaced.
